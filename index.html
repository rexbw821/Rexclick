What We DON'T Collect

  • We do NOT collect any keystrokes or typing data
  • We do NOT send any data to any server
  • We do NOT require an internet connection
  • We do NOT track usage, analytics, or behaviour

What the App Does

RexClick listens for keyboard events locally on your device solely to trigger sound playback. Keypress events are processed in memory and immediately discarded. Nothing is logged or stored.

Administrator Permission

The app requests admin rights to register a global keyboard hook — a standard Windows API used to listen for keypress events system-wide. This is the same mechanism used by many accessibility tools and keyboard remappers. It is used exclusively for sound triggering.
